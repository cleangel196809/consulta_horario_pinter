Módulo SISCA

La navegación unificada está preparada para SISCA. Este repositorio no contiene una API, modelo de datos, reglas de negocio ni mecanismo de autenticación de SISCA; por seguridad no se inventaron operaciones.

Para completar la integración se requiere: especificación de API o formato de intercambio, catálogo de datos, reglas de autorización, ambientes de prueba y responsable funcional.
